# Limax offensus — «Экспедиция за Слизнем Обиженным»

Одностраничный тренажёр обратной связи на чистых HTML/CSS/JS, без сборки и без бэкенда. Собран по разделу 11 проектного документа (`Джунгли_Игра_Проект_для_Claude_Code.md`).

## Запуск

Игра грузит `data/game.json` через `fetch`, поэтому открытие `index.html` напрямую как `file://` упрётся в CORS-ограничения браузера. Нужно раздать папку локальным статическим сервером, например:

```
python3 -m http.server 8000
# затем открыть http://localhost:8000/
```

Для публикации — GitHub Pages (см. раздел 11 проектного документа): все пути к ассетам относительные, регистр имён файлов в `game.json` совпадает с реальными файлами посимвольно.

## Структура

```
index.html       — разметка всех 7 экранов
style.css        — адаптивная вёрстка (мобильный/планшет/десктоп), шрифты, тач-таргеты
script.js        — движок: экраны, взвешенный выбор исхода, localStorage, звук, карточка результата
js/endings.js    — чистая функция матрицы концовок (раздел 2), общая для script.js и симулятора
data/game.json   — весь контент игры (готов, не редактировался)
scripts/simulate.js — Monte Carlo симулятор баланса концовок (вне игры, только для разработки)
assets/img, assets/audio — иллюстрации и звук (готовы, использованы как есть)
```

## Monte Carlo — баланс концовок

`node scripts/simulate.js [число_прогонов]` прогоняет четыре политики выбора варианта дня через ту же функцию `resolveEnding`, что использует движок игры, и печатает распределение по всем 6 концовкам для каждой:

- **random** — вариант каждого дня выбирается равновероятно (базовая линия);
- **warm** — всегда выбирается вариант, вручную отмеченный как «тёплый»: избегает прямого/конкретного разговора ради комфорта момента (расплывчатая похвала, молчаливое делегирование, «само рассосётся», тихо исправить самому за человека) — даже там, где это явно стоит продвижения;
- **hard** — всегда выбирается вариант, отмеченный как «жёсткий/конкретный» (приоритет фактам/стандарту, невзирая на состояние человека);
- **opportunistic** — не размечена вручную, а посчитана из данных: для каждого дня берётся вариант с максимальным `EV(боевой дух) − EV(продвижение)` (ожидаемые значения по весам исходов). Формализация гипотезы «специально собирать тёплые ветки там, где они не стоят прогресса, и осознанно проваливать конкретику там, где она доступна» — без риска ручной подгонки под желаемый результат.

`warm`/`hard` — прочтение смысла текста, а не число из `game.json`, поэтому разметка по дням печатается в выводе для проверки. Первая версия `WARM_MAP` (везде подряд «психологически лучший» вариант) для 7 из 10 дней совпала с вариантом, который и так лучший по обеим осям сразу — то есть измеряла «играть по учебнику», а не настоящий компромисс; текущая версия переразмечена конкретно под избегание.

Результат прогона на 50 000 партий на каждую политику:

| Концовка | random | warm (избегающий) | hard | opportunistic |
|---|---|---|---|---|
| 🏆 Реабилитация Тряпицына | 0.82% | 0.00% | 0.00% | 8.63% |
| 🌿 Крепкий полевой руководитель | 65.67% | 28.89% | 23.19% | **90.42%** |
| 🍄 Хороший человек, так себе результат | 0.00% | 0.00% | 0.00% | **0.95%** |
| 📊 Слизень найден, друзья — нет | 0.38% | 0.00% | 1.69% | 0.00% |
| 🌧️ Тряпицын снова не реабилитирован | 23.48% | **71.11%** | 43.82% | 0.00% |
| 💀 Конец экспедиции | 9.65% | 0.00% | **31.30%** | 0.00% |
| БД / П (среднее) | −10.4 / 72.2 | −53.0 / 4.9 | −136.9 / 41.8 | 176.8 / 109.2 |

Все 6 концовок достижимы при случайной политике. Неожиданный результат `warm`: избегание прямого разговора в этих данных **не** читается как забота — оно читается как безразличие (день 5 вариант V: «Светлана не уверена, что вы вообще заметили»; день 7 вариант V: данные просто теряются, а не «все спокойны»), поэтому средний БД у избегающей политики отрицательный (−53.0), и 71% партий садятся в «Тряпицын снова не реабилитирован» (низкие оба показателя), а не в «тёплую, но нерезультативную» зону.

`opportunistic` подтверждает гипотезу лишь частично, зато честно показывает почему. Опортунистическая карта по `EV(БД)−EV(П)`, посчитанная из данных:

| День | Выбор | EV(БД) | EV(П) |
|---|---|---|---|
| 1 | B | 29.0 | 14.3 |
| 2 | A | −12.0 | −8.5 |
| 3 | **G** | 7.3 | **−18.0** |
| 4 | B | 22.3 | 14.8 |
| 5 | B | 34.8 | 16.0 |
| 6 | A | 24.3 | 21.0 |
| 7 | **V** | −12.8 | −12.0 |
| 8 | B | 27.5 | 24.5 |
| 9 | B | 33.0 | 19.3 |
| 10 | A | 23.5 | 37.8 |

Только дни 3 и 7 реально дают вариант с низким/отрицательным EV(П) при сносном EV(БД) — на остальных 8 днях максимизация БД автоматически тащит за собой и максимизацию П, потому что в этих данных оба показателя у вариантов почти везде коррелируют напрямую (правильная по обеим осям техника здесь — не редкое совпадение, а сама идея дизайна). Поэтому политика перешла от «недостижимо» (0.00% у random/warm/hard) к «редко, но реально» (0.95%, 473 из 50 000) — она реально нашла узкую зону БД>150/П<30 через рулетку исходов на нижней границе распределения, а не системно её удерживает: среднее П у неё всё равно 109.2, далеко выше требуемого порога.

Политика `hard`, для сравнения, даёт чистый и ожидаемый сигнал: она стабильно попадает в варианты «дожимать факты, игнорируя состояние человека» — а именно к ним привязаны провальные ветки, отсюда 31.30% провала экспедиции, прямое следствие штрафа именно за эту стратегию, накопленного по всем 10 дням.

## Мобильный тест

Пройден чек-лист раздела 11.12: эмуляция iPhone SE и iPad Mini (Playwright, device emulation) — нет горизонтальной прокрутки ни на одном экране, все тач-таргеты ≥44×44px, кнопки вариантов реагируют на `:active` (не только на hover), звук стартует по тапу на «Начать экспедицию»/«Розпочати експедицію», переключатель языка не съезжает. Пройден полный цикл на 10 дней (все переходы, оба языка, сохранение/возобновление через `localStorage`, ветка провала, журнал экспедиции, экспорт карточки результата в форматах 1:1 и 9:16).

## Известное ограничение

Ассеты (`assets/img` + `assets/audio`) заведомо использованы как есть, без пересжатия — суммарно ~19 МБ (аудио ~8 МБ, иллюстрации ~11 МБ), больше ориентира 4–6 МБ из раздела 11.7 проектного документа. Автосжатие сознательно пропущено по договорённости — данные, картинки и звук использовались как есть.
